High-Level Goal
Build a single-page React/Tailwind UI called "Carameli." The aesthetic is "Glossy Game UI" with heavy caramel themes. Every element must appear to be 3D and liquid-smooth, using gradients and shadows rather than flat colors.

Visual Language (Tailwind + Custom CSS)
Logo: Render "Carameli" using a thick script font. Apply a text-shadow stack: 2px 2px 0px #5C3317, 4px 4px 0px #8B4513, 0px 8px 15px rgba(0,0,0,0.4). The text color should be a vertical gradient from #FFFFFF to #FFD37E.

Dripping Header: The top of the viewport is a thick caramel pour (bg-[#C15A10]). The bottom edge is a custom SVG path with deep "U" shaped squiggles. Add a border-b-4 border-[#FFF3CC]/30 to simulate light hitting the bottom of the drips.

The Gloss Effect: Apply a linear-gradient(to bottom, rgba(255,243,204,0.4) 0%, transparent 50%) as an overlay to all orange surfaces to create a "sheen."

Navigation Architecture
Sticky Circles: 4 circles (w-24 h-24) that appear "stuck" to the dripping header.

Visuals: Give them a 4px solid border in #5C3317. Use bg-gradient-to-br from-[#FFF8E7] to-[#E8D09E].

Hover Interaction: On hover, use Framer Motion to expand the circle into a rounded pill (w-64). Use a "spring" transition (stiffness: 300, damping: 20) to make it feel bouncy. Reveal the menu name in bold, chocolate-brown text.

Component Specs (The Content Boxes)
Structure: Create cards that look like the "items" in the reference image.

The "Dip": The top 1/3 of each card should have a "chocolate/caramel drip" SVG overlay that overlaps the content area.

Inner Glow: Use box-shadow: inset 0 4px 10px rgba(255,255,255,0.5) on the cards to make them look rounded and polished.

Styling: Background bg-[#F5E6CC], rounded corners 32px.
