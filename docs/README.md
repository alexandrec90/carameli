# Documentation

Durable project knowledge is tracked here. Generated output, raw captures, and personal
scratch notes belong in the ignored `artifacts/` and `.local/` directories — including any
VanillaLand/VanillaSoft material, which `.gitignore` keeps out of this repo entirely.

## Guide

- [Prototype roadmap](prototype-roadmap.md) — current integration roadmap
- [Plans](plans/) — active and completed session-sized plans
- [Operations](operations/) — diagnostics, firewall, and deployment-facing guidance
- [Product](product/) — UI guidance and skin design briefs
- [Reference](reference/) — source-system and compatibility research
- [Evidence](evidence/) — small, reviewable performance and test baselines

Current work in flight is tracked in [TODO.md](../TODO.md) at the repo root.
